# IPL Data Analytics Project

## Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project analyzes IPL (Indian Premier League) cricket data using Python and covers:

- Data Collection and Preparation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Sentiment Analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- BeautifulSoup
- TextBlob
- Jupyter Notebook

## Project Tasks

### Task 1 - Data Collection

- Loaded IPL dataset
- Inspected dataset structure
- Handled missing values
- Exported processed dataset

### Task 2 - Exploratory Data Analysis

- Analyzed IPL seasons
- Identified top winning teams
- Toss decision analysis
- Venue analysis
- Player of Match analysis

### Task 3 - Data Visualization

- Team performance charts
- Toss winner charts
- Venue analysis charts
- Seasonal match trends

### Task 4 - Sentiment Analysis

- Classified IPL comments into:
  - Positive
  - Negative
  - Neutral

## Key Insights

- Mumbai Indians emerged as the most successful team.
- CH Gayle received the highest number of Player of the Match awards.
- Eden Gardens hosted the highest number of IPL matches.
- Teams preferred fielding after winning the toss.
